Study guide · Dave Mark, 2009

Behavioral Mathematics for Game AI, as something you can build

The book spends 450 pages on one idea: turn everything an agent cares about into numbers on a common scale, shape those numbers with curves, combine them into one score per option, and then pick an option in a way that looks human. These pages compress that into six parts, each with widgets you can poke at.

Read this first: what the book does and does not contain

The Infinite Axis Utility System (IAUS) is not in this book. Dave Mark presented it later, in GDC talks from about 2013 onward. This book is the foundation it was built on: utility, response curves, normalisation, weighting, and selection.

Pages 1 to 5 summarise the book. Page 6 is my own bridge from the book to IAUS and to your GOAP planner. It is clearly marked, and it draws on Mark's later talks and common practice, not on the book's text.

The whole book in one picture

Every worked example in the book follows this pipeline. If you remember only one thing, remember this.

1. ObserveList the factors that matter to this decision.
→
2. MeasureGet a raw value for each: health, distance, ammo.
→
3. ShapeTurn value into utility with a response curve.
→
4. NormalisePut every utility on the same 0 to 1 scale.
→
5. CombineWeight and merge into one score per option.
→
6. SelectPick: best, or weighted random among the good ones.
→
7. RevisitRe-check at a sensible rate, with momentum.

Bridge to your project

How to use these pages

  • Read in order the first time. Each part uses terms from the one before. Parts 3, 4 and 5 are the ones you will come back to while coding.
  • Play with every "Try it" box. The point of the book is intuition for how numbers change behaviour. Dragging a slider teaches that faster than reading does.
  • Hover any plot to read exact values off the curve.
  • Coloured boxes mean: yellow is an example taken from the book, green is implementation advice, orange is material that goes beyond the book.

Vocabulary you will see everywhere

TermMeaningWhere
ValueThe raw, measurable amount of something: 40 health, 12 metres, 3 bullets.Part 2
UtilityHow much that amount matters to this agent, right now, for this decision. Usually not proportional to value.Part 2
Marginal utilityHow much one more unit is worth. It falls for most things (the tenth soldier) and rises for some (the last sliver of health).Part 2
Response curveA function, formula or lookup table, that maps an input to an output. The main tool for turning value into utility.Part 3
NormalisationRescaling a number into a fixed range, almost always 0 to 1, so it can be compared with others.Part 4
Weighted sumAdding several utilities together after multiplying each by how important it is.Part 4
Compartmentalised confidenceThe book's phrase for: verify each small piece alone, then trust it when you combine pieces.Parts 4, 5
StrobingAn agent flipping between two choices over and over. Cured with decision momentum.Part 5
